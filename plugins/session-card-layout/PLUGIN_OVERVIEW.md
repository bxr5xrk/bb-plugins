Choose the height and layout of Project Workspace session cards:

- **Поточний** keeps the current appearance.
- **Два рядки** puts status beside the title and time beside the preview.
- **Один рядок** shows a compact status glyph, title and time.

Choose in the plugin settings; the selection is saved and applies immediately. Disabling restores the original layout. Requires the installed Project Workspace session-height bridge.
