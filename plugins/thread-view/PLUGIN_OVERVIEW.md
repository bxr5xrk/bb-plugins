An easier-to-read thread screen.

The chat uses more of a wide window while each paragraph keeps a comfortable line length. Replies use lighter, slightly smaller type with clear gaps between paragraphs, lists, and headings, close to the Claude desktop app, and links and inline code stand out in blue and red. The prompt box is shorter on desktop, and its Send button becomes a quiet icon like the controls next to it.

Short updates Claude writes between tool calls, such as the text before a question, show as regular replies instead of hiding inside a collapsed "Thought" row. To do this, Thread View patches BB's built-in Claude Code provider and restarts it once.

Messages, code blocks, tools, drafts, and shortcuts behave as before. Disable Thread View to get BB's original screen back; the provider patch stays until BB is reinstalled or updated.
