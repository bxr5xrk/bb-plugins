Fast mode choices now survive leaving a chat and returning, even before a message is sent.

The plugin remembers each existing thread’s selected service tier separately for each provider and model. Turning Fast off is remembered too. Preferences survive reloading the app in the same browser or desktop profile.

It uses BB’s composer API and adds no controls. BB still decides which tiers a provider and model support. New-thread, queued-message, and sent-message editors are left to BB.

Preferences stay in local app/browser storage and do not sync between devices. Disable Fast Mode Memory to return to BB’s native behavior.
